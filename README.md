## Contents
This repo contains all of the data we generated during our project as well as the notebooks we made use of to help with data visualization and data analysis.

## Reproducibility
In order to reproduce our results, the following is required:
- Access to powerful GPU's (at least A100 with high-RAM options (80GB), preferably H100 for speed)
- OpenAI API key to run the LLM-as-a-Judge model with support for credits
- Hugging Face and GitHub API tokens to run everything flawlessly
